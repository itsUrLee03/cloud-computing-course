# Cloud Concepts & Daily Technology Reflection

## 1. Daily Cloud Services

In my daily personal and academic routines, I frequently rely on several cloud-based services:

1. **Google Drive:** Used for storing documents, spreadsheets, and collaborative academic files.
2. **Netflix:** Used for streaming video content on demand across multiple personal devices.
3. **GCash:** Used for digital financial transactions, online payments, and instant peer-to-peer transfers.

---

## 2. Service and Deployment Models

### Google Drive
* **Service Model:** **SaaS (Software as a Service)** — End users interact directly with fully managed storage and productivity apps through a web or mobile interface without managing servers or storage hardware.
* **Deployment Model:** **Public Cloud** — Hosted on Google's globally accessible cloud infrastructure and shared among multi-tenant users.

### Netflix
* **Service Model:** **SaaS (Software as a Service)** — Delivers end-user media streaming applications directly over the web without requiring infrastructure management.
* **Deployment Model:** **Public Cloud** — Runs on public cloud infrastructure (primarily AWS) to dynamically scale resources based on viewer demand worldwide.

### GCash
* **Service Model:** **SaaS (Software as a Service)** — Operates as a turnkey financial application layer for end-consumer transactions.
* **Deployment Model:** **Hybrid Cloud** — Utilizes public cloud infrastructure for high-availability user services while maintaining private cloud components for sensitive bank data and regulatory compliance.


## 3. Git & GitHub for Cloud Projects
**Version control is critical for cloud infrastructure** because it treats infrastructure as code (IaC), allowing teams to automate deployments, audit every configuration change, and instantly roll back to a safe state if an outage or error occurs.

**How GitHub helps:**

* **Collaboration:** Teams use **Pull Requests** to review and discuss infrastructure changes before deployment.
* **Tracking:** Every modification is logged with a detailed history of **who changed what, when, and why**.
* **Error Prevention:** **GitHub Actions** automatically test code and scan for security risks, while **Branch Protection** ensures unapproved changes never reach production.
